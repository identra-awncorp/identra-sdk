# Identra SDK

All SSI protocol logic of Identra (SD-JWT VC, OpenID4VCI, OpenID4VP, status list, trust list,
X.509 issuer authentication) lives in this SDK; `identra-server`, `identra-app` and
`identra-website` only do UI, HTTP and storage. The contract is
[`docs/architecture.md`](docs/architecture.md); the decisions behind it are ADR-0001 to ADR-0017.

## State after phases GĐ1–GĐ3 (cryptography, X.509, SD-JWT VC)

| Package | State |
|---|---|
| `@identra/sdk-core` | Implemented: injected interfaces, result model and the complete `ErrorCodes`, strict encodings (base64url, base64, UTF-8, hex), JWS sign / decode / verify with the ES256-only allow-list, EC P-256 JWK helpers and RFC 7638 thumbprints, ECDSA DER ⇄ r‖s, `parseCertificate` (strict DER, via `micro-key-producer`), `createCertificateChainValidator` (profiles `vc`, `status`, `request`, `trust-list`; one or two pinned roots), `did:jwk`; SD-JWT VC: `issueDiploma`, `issueProductEvent`, `issueCredential`, `createPresentation`, `decodeCredentialUnverified` (display only) and the verification policy `verifyCredential` (architecture §3, steps 1–9). Status list and trust list implementations come next; `TrustRegistry` and `StatusChecker` are interfaces |
| `@identra/sdk-core/webcrypto` | Implemented: `webCryptoVerifier`, `webCryptoHasher`, `webCryptoRandom`, `createWebCryptoSigner`, `generateWebCryptoKeyPair` on `globalThis.crypto` (Node, browsers; not React Native) |
| `@identra/sdk-server`, `@identra/sdk-app`, `@identra/sdk-client` | Empty shells that build; rebuilt in later phases |

The core main entry imports no platform library and uses no platform global: crypto, HTTP,
randomness and the clock are injected. ESLint enforces this, and a test bundles the entry with
esbuild `--platform=neutral` and runs it in a `node:vm` realm without `crypto`, `Buffer`,
`process` or `fetch` (a React Native proxy).

## Build and test

Node 22.12 or later, npm, OpenSSL 3.0 or later, bash.

```sh
npm ci
npm test        # typecheck + build, generate the test PKI into .pki/ if needed, run node:test
npm run build   # tsc -b
npm run lint
npm run example:gd2   # issue -> store -> present ho_ten + nganh -> verify, with the DEMO PKI
```

Tests use `node:test` only; `npm test` also runs `examples/gd2-e2e.mjs`. They run against the compiled output (`packages/*/test-dist`, git-ignored).
The test and demo certificates are generated by the OpenSSL scripts in [`scripts/pki/`](scripts/pki/README.md)
into `.pki/` (git-ignored); delete `.pki/` to regenerate. No private key is ever committed.

## Using the packages from the apps

Apps and the server install the packages with `file:` dependencies (ADR-0005); see
[`docs/local-file-dependency-testing.md`](docs/local-file-dependency-testing.md) for the mechanics
(its code samples show the removed demo API and are outdated).
